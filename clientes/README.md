# Clientes

Uma pasta por cliente, com a identidade que você criou para ele:

```
clientes/
  nome-do-cliente/
    briefing.md     (a partir de templates/briefing-cliente.md)
    DESIGN.md       (a partir de templates/DESIGN.md, validado com o lint do Google)
    referencias.md  (sites usados e o que foi aproveitado de cada um)
```

Com o tempo esta pasta vira a sua biblioteca de identidades: para um cliente novo do mesmo ramo, comece pelo DESIGN.md de um cliente parecido e mude a personalidade.

Não guarde aqui senhas, chaves de API nem dados pessoais de clientes.
